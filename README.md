# HyPRNN — FE² with hypernetwork PRNN surrogates

Multi-scale FE² analysis of woodchip–mycelium composites, with Physics-informed
Recurrent Neural Networks (PRNNs) as material surrogates. RVE microstructures
are generated by DEM particle deposition (YADE), meshed with GMSH, homogenized
with FEniCSx/dolfinx, and used to train JAX/Flax surrogate models that replace
the RVE at each macro-scale Gauss point.

## Installation

```bash
conda env create -f environment.yml
conda activate hyprnn_env
pip install -e .
```

**YADE must be installed separately** — it is a system package with its own
embedded Python, not part of the conda environment. On Ubuntu/Debian:

```bash
sudo apt install yade          # stable, runner: yade
# or the daily build (used here), see https://yade-dem.org/doc/installation.html
sudo apt install yadedaily     # runner: yadedaily
```

Only the particle deposition step runs under YADE; everything else (meshing,
training, FEM) runs in the conda environment. The batch script uses the
`yadedaily` runner by default; override with `YADE_BIN=yade` if you installed
the stable package.

## Workflow

1. **Deposition + meshing** (`yade/`): `batch_filler_dataset.py` deposits one
   RVE packing per filler fraction and meshes it. Run a single deposition
   manually with `yadedaily yade_woodchip_filler.py -- --filler_fraction 0.3`.
2. **Training data** (`scripts_surrogates/`): `create*Data.py` run RVE
   simulations on the meshes and store `{F, PK1, cauchy}.npy` sequences.
3. **Training** (`scripts_surrogates/`): `train_*.py` train PRNN / HyPRNN / NN
   surrogates into `trained_models/`.
4. **FE² studies** (`scripts_FEM/`): `validate_*.py`, `graded_ring_pressure.py`,
   `squeeze_hole.py`, `optimize_ring.py` compare surrogates against full FE²
   and run design optimizations.

Shared material constants (wood/fungi elastic properties) live in
`material_params.py`. Run scripts from within their own folder.
